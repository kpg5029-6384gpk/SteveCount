# Little Buddy modes and head-riding size

Press **J > Buddy options**, or **K > Character > Buddy options**.

**Head-riding size** changes only the buddy seated on your head. Drag from 8% to
60% of normal player-model scale; the existing 18% size is the default. Toggle
Head riding on and use F5 to see the change immediately. Your ordinary ground
follower size stays separate under K > Character > Character size. Reset
head-riding size restores 18%. Save & Done stores both settings across restarts.

**Streamer mode** displays the configured viewer HUD and overhead count/status
label. Their existing display and label preferences still apply. It permits the
existing optional gift-damage feature; gift damage still requires explicit opt-in,
an actual live connection and single-player.

**Regular mode** keeps Little Buddy without a viewer HUD, overhead viewer/status
tag, milestone alerts or gift-triggered damage. If the profile was HUD-only, choosing
Regular makes the character visible. Following, skins, head riding, random activity,
sounds, manual emotes and optional offline voice commands remain available.
No companion or internet is required for the buddy itself; voice commands still
require the companion and microphone Start control.

Choosing Regular disconnects TikTok and skips TikTok auto-connect on future game
starts. It retains the username and auto-connect preference. Returning to Streamer
reconnects if auto-connect was enabled; otherwise use K > Connect. Clicking Connect
or Reconnect also selects Streamer mode. The companion's microphone controls remain
independent; use Stop / mute voice to stop microphone capture.

Existing profiles default to Streamer and retain their prior appearance. This update
only needs the matching new JAR; the previous offline-voice companion is compatible.
